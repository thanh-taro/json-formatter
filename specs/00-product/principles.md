# Principles

- **PRN-01** — *Private by construction.* User content never leaves the device: no uploads, no
  analytics, no share links, no content stored between sessions. When in doubt, don't send.
- **PRN-02** — *Lossless.* Formatting changes only insignificant whitespace. Values, number
  spelling, key order and duplicate keys are kept exactly as written.
- **PRN-03** — *Errors that point.* Every problem has an exact location and a plain-language
  hint about the likely cause.
- **PRN-04** — *Never block.* The interface stays responsive regardless of input size; long work
  shows progress and can be cancelled.
- **PRN-05** — *Fits the host.* Looks and behaves like part of the portal when embedded, and
  remains fully usable on its own.
