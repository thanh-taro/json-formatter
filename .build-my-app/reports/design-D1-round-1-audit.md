# Design D1 (components) — round 1 audit

Scope: design/canvas/CMP-{Toolbar,Editor,StatusBar,IssuePanel,TreeView,DropOverlay}.dc.html, Main.dc.html (light), canvas.json.
Checked against: specs component/feature files, copy.md, tokens.json, style.md, adapters/design.md.
Method: scripted comparison of the --var colour sets (both themes, every file) and every data-copy ID/text against tokens.json/copy.md, plus manual read.

## What passes
- All colour custom properties in every file equal tokens.json (dark and light). No colour mismatches.
- Every "Variants & states" row has an artboard in dark and light, labeled `<CMP-ID> / <variant> / <theme>` (via sc-for), for all six components.
- All data-copy IDs exist in copy.md; hint texts match exactly.
- Canvas note: `#0B0810` backdrop is canvas chrome (not a finding). `./support.js` is referenced but not in design/canvas/ (canvas runtime; confirm it is supplied by the host).

## Summary
No blockers. Colour tokens fully correct. Main gaps: missing variants for spec-owned strings (loading/exporting/confirm/toast/clipboard whole-document fallback), several UI strings with no COPY ID (partly copy.md gaps), a11y semantics (indent selector, editor, issue list, status role), and untokenised values (shadow, opacity, 11px/14px, 22/30px heights).
